## Overview ##
This is an intelligent nutritional consultant Agent that transitions from simple text reasoning to a multi-tool powerhouse.
The agent is able to understands nutrition concepts and is equipped Storage SDK tool to archive ingredient images and
a Vision tool to "read" and analyze those images.
This is a fully functional orchestrator that can take an uploaded photo of a food label,
store it in a cloud bucket for record-keeping, and immediately provide "Healthy Hints" for each ingredient.

## How to Run ##
Install ADK
'pip install google-adk'

Bash
'adk run healthy_hints'

on web
bash
'adk web'
